客服支援

如果你在使用 DineCard 時遇到問題，可以透過公開支援單回報。我們會依問題內容進行確認。

一般問題

適合回報：App 無法正常使用、購買/還原問題、帳號刪除問題、餐廳卡片或搜尋異常、其他功能問題。

建立支援單

提交支援單需要 GitHub 帳號。請不要貼上密碼、完整交易憑證、Apple ID、信用卡或其他敏感資訊。

付款與退款

iOS 付款由 Apple App Store 處理。DineCard 可以協助確認 App 內權益或還原狀態，但退款申請由 Apple 依其政策處理。

取消訂閱

刪除 DineCard 帳號不會取消 Apple 訂閱。請在 iPhone 的 Apple ID 訂閱管理頁面查看或取消自動續訂。

刪除帳號／資料

請使用 App 內「設定 → 帳號與資料 → 刪除我的資料」。如果流程發生錯誤，可建立支援單，並附上錯誤畫面與發生時間；請勿提供敏感憑證。

不當廣告

若要回報不適當、誤導或不符合年齡的廣告，請使用專用的 檢舉不當廣告 頁面。
