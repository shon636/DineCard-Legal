隱私權政策

生效日期：2026-09-17

DineCard 重視您的隱私。本政策說明 DineCard 在目前版本中可能處理的資料、用途、第三方服務以及您可採取的控制方式。

1. 我們處理哪些資料

  • 位置資料：只有在您授權後，DineCard 才會使用前景位置，以提供附近餐廳、距離與地圖等功能。目前版本不要求背景或「永遠」位置權限。
  • 匿名 App 識別與安全資料：DineCard 使用匿名的 Project/DineCard Principal 與必要的安全憑證來提供伺服器功能、權限判定、獎勵、購買驗證及防止濫用。這不是 email、社群帳號或公開個人檔案。
  • 餐廳與搜尋資料：個人餐廳卡片、收藏與搜尋資料在目前 V1 以本機資料為主；只有功能需要時才會將必要請求送往後端或第三方服務。
  • 購買與交易資料：如果您購買或還原 App Store 商品，DineCard 可能將 Apple 簽署的交易證明及必要交易識別資料傳送到後端，用於驗證會員、去除廣告、Token 權益、還原購買、防詐與防止同一交易重複兌換。
  • 廣告與裝置相關資料：DineCard 使用 Google Mobile Ads 顯示 Banner、Interstitial 與使用者自願觀看的 Rewarded 廣告。Google 可能依您的地區、同意選擇與其服務設定處理裝置或廣告相關資料。DineCard 目前不以自身程式宣稱或要求跨 App 追蹤。

2. 我們如何使用資料

資料只用於提供 DineCard 功能、搜尋與附近餐廳體驗、權益與購買驗證、廣告與同意管理、安全、防詐、防止重複交易、除錯與符合法律義務等合理目的。

3. 第三方服務

DineCard 可能使用 Apple App Store / StoreKit、Google Maps、Google Mobile Ads / User Messaging Platform，以及 Supabase 等基礎設施。這些服務可能依其自己的隱私政策處理資料。

4. 廣告與隱私選項

在適用地區，DineCard 會透過 Google 的 User Messaging Platform 取得必要的廣告同意，並在 SDK 判定需要時提供隱私權選項。若您看到不適當或不符合年齡的廣告，可使用 檢舉不當廣告 頁面回報。

5. 帳號／Principal 刪除

您可以在 App 內的「設定 → 帳號與資料 → 刪除我的資料」提出刪除。成功刪除後，DineCard 會刪除可刪除的 Principal 與其關聯伺服器資料，並清除裝置上的目前憑證與工作階段。

刪除 DineCard 帳號或資料不會取消 Apple 訂閱，也不會刪除您的 Apple ID。 若您有自動續訂訂閱，請另外在 Apple 的訂閱管理頁面取消。

6. 必要的安全留存

為防止已退款、已撤銷或已兌換的 Apple 交易再次被利用，DineCard 可能在帳號刪除後保留最小化的交易重放／安全識別紀錄。這類紀錄的目的僅限安全、防詐、退款或爭議處理，不保留已刪除帳號不必要的個人內容。

7. 資料保存

我們只在提供功能、安全、法令、稅務、退款、爭議處理或防詐所合理必要的期間內保存資料。能刪除的資料會依產品功能與刪除流程移除；必要的最小化安全紀錄可能保存較長時間，以避免同一交易再次取得權益。

8. 兒童

DineCard 並非專為未滿法定年齡的兒童設計。我們不會刻意建立以兒童為目標的個人資料收集功能。

9. 政策更新

若 DineCard 的資料處理方式有重大變更，我們會更新本頁與生效日期。送審與正式版本的公開政策應與實際 App、第三方 SDK 與正式環境設定一致。

10. 聯絡我們

如有隱私或資料相關問題，請前往 客服支援。
