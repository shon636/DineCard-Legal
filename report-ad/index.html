檢舉不當廣告

如果你在 DineCard 看到不適當、誤導、令人不舒服或可能不符合年齡的廣告，請回報給我們。我們會保留回報資訊供調查，必要時也可能依廣告供應商的工具進一步處理。

建議提供

  • 看到廣告的大約日期與時間
  • 廣告出現的位置（Banner / Interstitial / Rewarded）
  • 廣告品牌或內容描述
  • 問題類型，例如成人內容、暴力、賭博、誤導、仇恨或其他不適當內容
  • 若方便，可附截圖；請先遮蔽任何個人敏感資訊

回報廣告

提交回報需要 GitHub 帳號。請不要貼上 Apple ID、付款資料、密碼或其他敏感資訊。

隱私

廣告回報只應包含處理該問題所需的資訊。我們不要求你提供完整裝置識別碼、Apple ID、付款憑證或登入資訊。

其他問題

若問題不是廣告內容本身，而是付款、帳號或 App 功能，請改用 客服支援。
